# Gokul Chatbot (WhatsApp Bot)

An automated WhatsApp chatbot for **Gokul Tex Print** designed to handle ticketing workflows (support issues) and deliver automated ERPNext reports[cite: 1].

📄 **[View Full User Manual PDF](https://drive.google.com/file/d/1MqRTz163o567M4d8TPGp76L11zuGh86K/view)**

---

## 🚀 Getting Started

1. **Add Contact:** Save the official bot number to your phone's contact list:
   * **Phone Number:** `+91*****92625`[cite: 1]

2. **Start Conversation:** Open WhatsApp and send a greeting message (e.g., `Hi` or `Hello`) to start the main menu session[cite: 1].

---

## 📋 Features & Functionalities

### 1. Main Menu Options

After sending `Hi` / `Hello`, tap **Please Select** to choose from the menu[cite: 1]:
* **Tickets:** Create a new ticket or track existing status[cite: 1].
* **ERPNext Reports:** Receive automated sales or job work reports[cite: 1].
* **Exit:** Exit current mode / interactive session[cite: 1].

---

### 2. Creating a Ticket

Navigate to **Tickets** > **Please Select** to choose your preferred ticket creation method[cite: 1]:

#### 🎤 Option A: Create Voice Ticket
1. Select **Create Voice Ticket** from the menu[cite: 1].
2. Press and hold the WhatsApp microphone button to record and send your voice note detailing the issue, concerned staff, and preferred reminder date[cite: 1].
3. The chatbot will process the audio and display extracted details (Subject, Regarding, Reminder Date, Priority)[cite: 1].
4. Review the details carefully[cite: 1]:
   * Select **Yes** to confirm and generate the ticket[cite: 1].
   * Select **No** to re-record if there is any error[cite: 1].

---

#### 💬 Option B: Create Chat Ticket
1. Select **Create Chat Ticket** from the menu[cite: 1].
2. Type and send your issue details including the concerned person's name (e.g., `PO error @dinesh`)[cite: 1].
3. Review the extracted ticket details on-screen[cite: 1]:
   * Select **Yes** to generate the ticket[cite: 1].
   * Select **No** to re-type if modifications are needed[cite: 1].

---

### 3. Tracking & Managing Tickets

To view or manage existing support tickets[cite: 1]:
1. Go to **Tickets** > **Check Existing Ticket**[cite: 1].
2. Choose from the available actions[cite: 1]:
   * **My Tickets:** Tap to view a complete list of all tickets generated by you along with their Ticket ID, Subject, Regarding staff, Status (e.g., Open), and Reminder info[cite: 1].
   * **Assigned to Me:** View tickets specifically allocated to your profile[cite: 1].
   * **For Close Ticket:** Select to close active tickets[cite: 1].
