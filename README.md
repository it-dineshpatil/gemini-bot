# Gokul Chatbot (WhatsApp Bot)

An automated WhatsApp chatbot for **Gokul Tex Print** designed to handle ticketing workflows (support issues) and deliver automated ERPNext reports.

---

## 🚀 Getting Started

1. **Add Contact:** Save the official bot number to your phone's contact list:
   * **Phone Number:** `+918511492625`

2. **Start Conversation:** Open WhatsApp and send a greeting message (e.g., `Hi` or `Hello`) to start the main menu session.

---

## 📋 Features & Functionalities

### 1. Main Menu Options

After sending `Hi` / `Hello`, tap **Please Select** to choose from the menu:
* **Tickets:** Create a new ticket or track existing status.
* **ERPNext Reports:** Receive automated sales or job work reports.
* **Exit:** Exit current mode / interactive session.

---

### 2. Creating a Ticket

Navigate to **Tickets** > **Please Select** to choose your preferred ticket creation method:

#### 🎤 Option A: Create Voice Ticket
1. Select **Create Voice Ticket** from the menu.
2. Press and hold the WhatsApp microphone button to record and send your voice note detailing the issue, concerned staff, and preferred reminder date.
3. The chatbot will process the audio and display extracted details (Subject, Regarding, Reminder Date, Priority).
4. Review the details carefully:
   * Select **Yes** to confirm and generate the ticket.
   * Select **No** to re-record if there is any error.

---

#### 💬 Option B: Create Chat Ticket
1. Select **Create Chat Ticket** from the menu.
2. Type and send your issue details including the concerned person's name (e.g., `PO error @dinesh`).
3. Review the extracted ticket details on-screen:
   * Select **Yes** to generate the ticket.
   * Select **No** to re-type if modifications are needed.

---

### 3. Tracking & Managing Tickets

To view or manage existing support tickets:
1. Go to **Tickets** > **Check Existing Ticket**.
2. Choose from the available actions:
   * **My Tickets:** Tap to view a complete list of all tickets generated by you along with their Ticket ID, Subject, Regarding staff, Status (e.g., Open), and Reminder info.
   * **Assigned to Me:** View tickets specifically allocated to your profile.
   * **For Close Ticket:** Select to close active tickets.
