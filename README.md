# Gokul Chatbot (WhatsApp Bot)

An automated WhatsApp chatbot for **Gokul Tex Print** designed to handle ticketing workflows (support issues) and deliver automated ERPNext reports[cite: 1].

---

## 🚀 Getting Started

1. **Add Contact:** Save the official bot number to your phone's contact list:
   * **Phone Number:** `+918511492625`[cite: 1]
2. **Start Conversation:** Open WhatsApp and send a greeting message (e.g., `Hi` or `Hello`) to start the main menu session[cite: 1].

---

## 📋 Features & Functionalities

### 1. Main Menu Options
After sending `Hi` / `Hello`, tap **Please Select** to choose from:
* **Tickets:** Create a new support ticket or track existing status[cite: 1].
* **ERPNext Reports:** Receive automated sales or job work reports[cite: 1].
* **Exit:** End current interactive session[cite: 1].

---

### 2. Creating a Ticket

Navigate to **Tickets** > **Please Select** to create or check tickets[cite: 1]:

* **🎤 Voice Ticket (Create Voice Ticket):**
  1. Select *Create Voice Ticket*[cite: 1].
  2. Press and hold the WhatsApp microphone button to send a voice note detailing your issue, concerned person, and preferred reminder date[cite: 1].
  3. The chatbot extracts ticket details (Subject, Regarding staff, Priority)[cite: 1].
  4. Confirm with **Yes** to generate the ticket or **No** to retry[cite: 1].

* **💬 Chat Ticket (Create Chat Ticket):**
  1. Select *Create Chat Ticket*[cite: 1].
  2. Type your issue details including the concerned staff (e.g., `PO error @dinesh`)[cite: 1].
  3. Review parsed details on-screen and select **Yes** to confirm[cite: 1].

---

### 3. Tracking & Managing Tickets

* **Check Existing Ticket:**
  1. Go to **Tickets** > **Check Existing Ticket**[cite: 1].
  2. Tap **My Tickets** to view a full list of open/closed tickets with details including Ticket ID, Subject, Status, and Reminder info[cite: 1].
  3. Select **Assigned to Me** to view tickets allocated to your profile[cite: 1].
  4. Select **For Close Ticket** to close active tickets[cite: 1].
