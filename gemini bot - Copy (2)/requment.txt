Project Flow
============

1. WhatsApp chatbot

The chatbot is configured in the 11za chatbot builder:
https://app-v2.11za.in/chatbot

The chatbot sends text, audio, menu selections, and confirmation responses
to the Flask webhook.

1 11z chatbot trigger 

2. Flask webhook

        Receives incoming WhatsApp webhook requests and routes text and audio
        messages to the appropriate analysis function.

1. Message analysis

Text message:
        api_endpoint.py
                -> ai_chat_ana.py
                -> Gemini API
                -> JSON ticket details

Audio message:
        api_endpoint.py
                -> Audio_repy_analy.py
                -> downloads and saves the audio file
                -> ai.py
                -> Gemini API
                -> JSON ticket details

The extracted ticket details contain the subject, concerned person, reminder
date, and priority.

4. Ticket confirmation

Template_send.py
        Sends the extracted ticket details to WhatsApp for confirmation.

The user's Yes or No response is received by the webhook. Pending ticket
data is kept in memory while the confirmation workflow is active.

5. Ticket creation

User response = Yes
        -> insert.py
        -> creates an Issue in ERPNext
        -> uploads an audio attachment when applicable
        -> notication.py
        -> sends ticket details and notifications through WhatsApp

User response = No
        -> cancels the pending ticket and asks    Again Type | Back menu | Exit 

6. Supporting modules

whatsapp_mes_rece.py
        Currect Not User  
        Alternative webhook handler for incoming text and audio messages.

whatsapp_send_text.py
        Sends WhatsApp text messages through the 11za API.

security.py
        Loads WhatsApp, Gemini, and ERPNext credentials from .env.

number.json
        Stores registered WhatsApp numbers and names.

web.py and webpage.py
        Provide the Streamlit admin panel for managing registered numbers.

main.py
        Fetches customer information from ERPNext.

log.py
        Saves message and reply logs.

scheduler copy.py
        Calls the ERPNext fetch_ticket Server Script API for open tickets whose
        reminder date has arrived.

ticket_fetch.py
        Fetches open tickets and assigned tickets from ERPNext.
